Anti-Entropy Gossip

How systems like Cassandra and Dynamo repair stale data using Merkle Trees.

In an AP (Available/Partition tolerant) database, nodes accept writes even when other nodes are down. When a stale node comes back online, the cluster uses Gossip Protocol and exchanges Merkle Trees in the background to detect inconsistencies and silently repair the stale node (Anti-entropy).

Click a node to pause/unpause it. Then write data, unpause the node, and start gossip to watch it heal.
