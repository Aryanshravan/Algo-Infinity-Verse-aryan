Quotient Filter Visualizer

A space-efficient probabilistic data structure alternative to Bloom Filters. It splits a hash into a quotient (index) and remainder, using 3 metadata bits per slot to resolve collisions.

Hashing Process

Enter a string to see how it hashes.

The Quotient acts as the target array index. The Remainder is the value actually stored in the slot to verify the element.

Metadata Bits:

  • O (is_occupied): 1 if at least one inserted element's quotient points to this slot.
  • C (is_continuation): 1 if the remainder in this slot belongs to the same quotient as the previous slot's remainder.
  • S (is_shifted): 1 if the remainder is not in its natural slot (due to a collision).
