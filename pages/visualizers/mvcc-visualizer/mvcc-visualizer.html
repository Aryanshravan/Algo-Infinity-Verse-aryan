MVCC Engine: Active

Database Controls

Simulate MVCC (Multi-Version Concurrency Control) updates. Instead of overwriting data, an update creates a new row version.

How MVCC Works

  • Live Tuple: The current active version of a row.
  • Dead Tuple: Old versions kept for concurrent readers, causing bloat over time.
  • Vacuum: Scans pages to reclaim space from dead tuples.
